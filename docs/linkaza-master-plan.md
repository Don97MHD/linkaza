# خطة Linkaza الشاملة — هوية بصرية + سيو احترافي + نصوص تبيع وتتأرشف

**التاريخ:** 22 تموز 2026
**الموقع:** https://linkaza.com/ — منصة بيع باك لينك (Next.js 13)
**المرجع/المنافس:** https://bazoom.com/
**الهدف:** موقع "خرافي" بصرياً، يتصدّر جوجل، ويبيع.

## 1. أين نحن الآن (تشخيص صريح)

موقعك مبني على قالب جاهز (`xisen-next`، نسخة home-7) واشتغلت عليه لتصير Linkaza. الفكرة والقيم مقتبسة من bazoom تقريباً حرفياً (80,000+ ناشر، بدون اشتراك، دعم 24/7، Marketplace ذكي، خدمة محتوى، Strategy Builder، Analytics). المشكلة إنو أخذت **الفكرة** بس ما أخذت **الأشياء يلي بتخلّي bazoom يتصدّر**.

### نقاط القوة الموجودة
- بنية Next.js نظيفة ومنظّمة (297+ مكوّن، pages router).
- الصفحات الأساسية موجودة: marketplace, pricing, solutions, agencies, consultants, businesses, publishers, content-service, strategy-builder, analytics, about, blog, contact.
- مكتبات جاهزة للأنيميشن: `framer-motion`, `aos`, `react-slick` (بس غير مستغلّة).
- ملف `llms-full.txt` موجود (خطوة ذكية لِـ AI search).
- بنية أسعار واضحة: Standard $70، Premium $150، Authority $300، محتوى $40.

### الثغرات الحرجة (مرتّبة حسب الأثر)

| # | الثغرة | التأثير | الدليل |
|---|--------|---------|--------|
| 1 | **صفر Structured Data (Schema)** بكل الموقع | جوجل ما بيفهم إنك Organization/Product/FAQ — بتخسر Rich Results | `grep` رجّع 0 ملفات فيها `ld+json` |
| 2 | **SEO ثابت لكل الصفحات** — نفس العنوان والوصف لكل صفحة | كل صفحة بتتنافس على نفس الكلمة، وجوجل بيشوف تكرار | `seo.jsx` فيه title/description مكتوبين hardcoded |
| 3 | **لا Open Graph ولا Twitter Cards** | روابطك بتطلع بلا صورة/عنوان بالسوشال والواتساب | `seo.jsx` ما فيه أي og:/twitter: |
| 4 | **لا canonical** | خطر Duplicate content | غير موجود |
| 5 | **محتوى رقيق وعام** | جوجل بيصنّفو "thin content" — bazoom عندو 2000+ كلمة بالهوم لحالها | مقارنة مباشرة |
| 6 | **الأنيميشن قديم** (WOW.js/AOS بس) | إحساس "قالب 2019" مش "منصة 2026" | `hero-area.jsx` يستخدم `wow fadeInUp` |
| 7 | **خطأ بالخط** `display=swapj` | الخط ما بيتحمّل صح، وممكن CLS | `_document.jsx` سطر 8 |
| 8 | **robots.txt فيه توجيه مخترع** `Clean:` | جوجل بيتجاهلو، بس بيوحي بقلة احتراف | `robots.txt` سطر 10 |
| 9 | **sitemap ثابت وقديم** — كل التواريخ 2025-10-24 | `changefreq daily` كذبة لجوجل → بيقلّل الثقة | `sitemap.xml` |
| 10 | **زر عربي بلا محتوى عربي** + `lang="en"` ثابت | تخسر سوق كامل (السعودية/الخليج) بلا hreflang | `_document.jsx` + العلم بالناف |

## 2. تحليل الفجوة: bazoom مقابل linkaza

| العنصر | Bazoom (لِيش متصدّر) | Linkaza (الوضع الحالي) |
|--------|---------------------|------------------------|
| **المحتوى** | 2000+ كلمة بالهوم: تعريف، أنواع الـ link building، guest posting، broken links، PR... | 3–4 فقرات عامة قصيرة |
| **الربط الداخلي** | يربط لعشرات المقالات الداعمة (backlinks, toxic backlinks, packages...) | ربط أساسي بس |
| **المدونة** | مقالات محدّثة بتواريخ (يونيو 2026)، تصنيفات (AI, GEO, SEO) | صفحة blog فاضية/قالب |
| **Schema** | كامل: Organization, Article, canonical, OG, Twitter | صفر |
| **إشارات الثقة** | جوائز G2/SiGMA، عناوين فعلية (آرهوس، كوبنهاغن، ميامي)، CVR، اقتباسات المؤسس، تقييمات بأسماء | تقييمات مكرّرة بـ3 أسماء وهمية (David/James/Sarah مكرّرين) |
| **السرعة** | WordPress + WP Rocket (كاش قوي) | Next.js (ممتاز محتملاً، بس محتاج تحسين صور/خطوط) |
| **الأقسام** | 6 شرائح جمهور + 6 ميزات | 4 شرائح + 3 ميزات |

**الخلاصة:** الفرق مش بالتصميم بس — الفرق **عمق المحتوى + التقنيات + الثقة**. لو عملنا أحلى تصميم بالعالم وما عالجنا هدول، ما رح نتصدّر.

## 3. الخطة بمراحل

سننفّذ 5 مراحل بالترتيب. كل مرحلة قابلة للتسليم لحالها وبتشتغل بلا ما تنتظر يلي بعدها. الوقت التقديري افتراضي (جلسات عمل معي).

### المرحلة 0 — أساس SEO التقني (الأولوية القصوى — P0)
> *ليش أول: هي رخيصة التنفيذ وأعلى مردود. بلا هالأساس، أي محتوى أو تصميم منكتبو بيضيع.*

1. **إعادة بناء مكوّن `seo.jsx`** ليقبل props لكل صفحة: `title`, `description`, `canonical`, `ogImage`, `keywords`, `schema`. عنوان ووصف فريد لكل صفحة من الـ21.
2. **إضافة Open Graph + Twitter Cards** لكل صفحة (صورة 1200×630، عنوان، وصف).
3. **إضافة canonical** ديناميكي لكل صفحة.
4. **إضافة JSON-LD Schema:**
   - `Organization` + `WebSite` (بالهوم) مع `sameAs` للسوشال.
   - `Product` / `Service` + `AggregateRating` لصفحات الأسعار/الخدمات.
   - `FAQPage` لأي صفحة فيها أسئلة.
   - `BreadcrumbList` للصفحات الداخلية.
   - `Article` لمقالات المدونة.
5. **إصلاح الخط** (`swapj` → `swap`) وتحميل الخطوط محلياً (`next/font`) لسرعة وثبات.
6. **تنظيف robots.txt** (حذف `Clean:`) وربط sitemap صح.
7. **sitemap ديناميكي** يتولّد عند البناء بتواريخ `lastmod` حقيقية و`changefreq` صادقة.
8. **hreflang** جاهزية للعربي (`en` + `ar`) إذا قرّرنا نطلق نسخة عربية.

**المخرجات:** موقع مقروء بالكامل لجوجل، روابط تطلع صح بالسوشال، وأهلية Rich Results.

### المرحلة 1 — الهوية البصرية الجديدة الكاملة (P0/P1)
> *اخترت "هوية جديدة كاملة". هدفنا إحساس منصة SaaS 2026 راقية، مش قالب.*

1. **نظام ألوان جديد** (Design Tokens بـ CSS variables):
   - لون أساسي واحد قوي مميّز (نبتعد عن الأزرق التقني المكرّر — نقترح تدرّج بنفسجي/إلكتريك أو أخضر زمردي مثل bazoom بس ببصمة خاصة).
   - ألوان دلالية (نجاح/تحذير)، ورمادي محايد متدرّج، ووضع داكن أنيق.
2. **الخطوط (Typography):** خط عناوين حديث (مثل Sora / Clash / Satoshi) + خط نص مقروء (Inter). مقياس typographic scale واضح.
3. **اللوغو:** تحسين/إعادة رسم `linkaza_white.svg` — نسخة فاتحة وداكنة، وأيقونة مربّعة للـfavicon والسوشال.
4. **إعادة تصميم الـHero:** عنوان أقوى، sub-headline يبيع، CTA واضح، ومشهد dashboard حقيقي أو 3D mockup بدل الصورة الحالية.
5. **مكتبة مكوّنات موحّدة:** أزرار، كروت، badges، أقسام — بنظام spacing وradius وshadow ثابت.
6. **أيقونات موحّدة** (مجموعة واحدة متسقة بدل خليط الحالي).

**المخرجات:** `design-system.css` + هوم بيج جديد + دليل هوية مصغّر.

### المرحلة 2 — الأنيميشن والتفاعل (P1)
> *"أنيميشن وقصص خرافية" — بس بذوق، ما يضرّ السرعة ولا الـSEO.*

1. **استبدال WOW.js/AOS القديم** بـ `framer-motion` (مثبّت أصلاً) لِـ:
   - Scroll-reveal ناعم للأقسام (fade/slide/stagger).
   - Micro-interactions على الأزرار والكروت (hover, tap).
   - عدّادات متحرّكة للأرقام (80,000 ناشر، إلخ) — `react-countup` مثبّت.
2. **Hero متحرّك:** عناصر تطفو (parallax خفيف)، gradient متحرّك، أو mockup داشبورد يتحرّك.
3. **انتقالات صفحات** ناعمة (page transitions).
4. **احترام `prefers-reduced-motion`** وأداء 60fps — الأنيميشن ما لازم يأخّر LCP.

**المخرجات:** طبقة حركة موحّدة، سريعة، وبتعطي إحساس "premium".

### المرحلة 3 — إعادة كتابة النصوص (أسلوب أورويل) + محتوى طويل يتأرشف (P0 للمحتوى)
> *هي المرحلة يلي بتصنع الفرق بالترتيب. أورويل = وضوح يبيع ويتأرشف.*

**قواعد أورويل الستة (من "Politics and the English Language") كدليل كتابة:**
1. ما تستخدم استعارة/كليشيه شفتها كتير مطبوعة.
2. ما تستخدم كلمة طويلة إذا القصيرة بتكفّي.
3. إذا فيك تشيل كلمة، شيلها.
4. استخدم المبني للمعلوم مش المجهول.
5. ما تستخدم مصطلح أجنبي/علمي إذا في مقابل يومي.
6. اكسر أي قاعدة قبل ما تكتب شي بشع.

**ليش هالأسلوب مثالي للسيو:** جوجل (وأدوات AI search) بيكافئ الوضوح، الجمل القصيرة، والإجابة المباشرة. النص الواضح = readability أعلى = وقت بقاء أطول = ترتيب أفضل.

**الشغل الفعلي:**
1. إعادة كتابة **كل الصفحات الـ21** بنصوص فريدة، واضحة، تبيع، وغنية بالكلمات المفتاحية طبيعياً (مش حشو).
2. **محتوى طويل بالهوم** (1500–2500 كلمة): ما هو الـlink building، أنواعه (guest posting، link insertions، broken links، digital PR)، ليش مهم، كيف Linkaza بيحلّه — مثل ما bazoom عامل بالضبط، بس بأسلوبنا.
3. **صفحات pillar + supporting** للكلمات المفتاحية المستهدفة (backlinks, buy backlinks, guest posting, DA/DR...) مع ربط داخلي محكم.
4. **تقييمات وإشارات ثقة حقيقية** (نستبدل الأسماء الوهمية المكرّرة) — أرقام، شعارات، ضمانات.
5. **FAQ حقيقي** لكل صفحة خدمة (يغذّي FAQ Schema من المرحلة 0).

**المخرجات:** نصوص جاهزة لكل صفحة + هيكل محتوى (content map) للكلمات المفتاحية.

---

### المرحلة 4 — تحسين البيع والتحويل (Conversion) (P1)
> *الموقع لازم "يبيع" — مش بس يبيّن حلو.*

1. **CTA واضح ومتكرّر** بذكاء (فوق الطية، بعد كل قسم قيمة، بالفوتر).
2. **Social proof** قوي: عدد الروابط المُنجزة، شعارات عملاء، تقييمات Trustpilot/G2 (لو متوفّرة)، ضمانات.
3. **جدول أسعار محسّن** مع "الأكثر شعبية"، ومقارنة، وإزالة الاحتكاك.
4. **صفحات هبوط (Landing) مخصّصة** لكل شريحة (agencies, consultants...) بعرض قيمة مختلف.
5. **نماذج بسيطة** + دعوة "احجز مكالمة" مثل bazoom.
6. **إشارات أمان الدفع والثقة** قرب الأزرار.

**المخرجات:** مسار تحويل واضح من الزيارة → التسجيل.

---

### المرحلة 5 — محرّك المحتوى/المدونة للأرشفة المستمرة (P2 — مستمر)
> *bazoom بيتصدّر لأنو بينشر باستمرار. الترتيب بيتبني بالوقت.*

1. **مدونة فعّالة** بتصميم نظيف، تصنيفات (SEO، Link Building، AI/GEO)، وschema مقالات.
2. **تقويم محتوى** — مقالات تستهدف كلمات "معلوماتية" تجيب زوار وتربط لصفحات البيع.
3. **تحديث دوري** للـsitemap والمحتوى (إشارة نشاط لجوجل).
4. (بعد ما تتحرّر مساحة القرص) **ربط Search Console** لسحب بيانات آخر 28 يوم وبناء القرارات على الأرقام الفعلية: صفحات ظهور عالي/نقر منخفض → إصلاح عناوين؛ كلمات "striking distance" (ترتيب 5–20) → تقوية محتوى وربط داخلي.

**المخرجات:** نمو عضوي مستمر مبني على بيانات.

## 5. الخطوة التالية المقترحة

نبلّش بـ**المرحلة 0** فوراً — إعادة بناء `seo.jsx` وإضافة Schema/OG لكل الصفحات. هي أعلى مردود وأسرع نتيجة، وبتفتح الباب للباقي. بالتوازي نبلّش **الهوية البصرية** (نظام الألوان والخطوط) لأنها مستقلة.

**قرارات بحاجة من المالك قبل المرحلة 1 (الهوية):**
- اتجاه اللون: نبتعد عن أزرق تقني؟ في لون مفضّل؟
- في لوغو نهائي أو نعيد رسمو؟
- بدنا نطلق نسخة عربية فعلية (للسوق الخليجي) ولا نضل إنجليزي؟

**تنبيهان مهمّان:**
- **مساحة القرص:** بيئة سحب بيانات Search Console كانت موقوفة بـ Cowork لحتى تتحرّر مساحة. بـ Claude Code المحلي تقدر تشغّلها عبر service-account JSON.
- **الجودة قبل الكمية:** جوجل اليوم بيعاقب الروابط المشتراة منخفضة الجودة (تحديثات Panda/Penguin). محتوى أصلي وقيمة حقيقية = استدامة. هالمبدأ لازم ينعكس بالنصوص.

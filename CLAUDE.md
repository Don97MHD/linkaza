# Linkaza marketing site

This repository contains the public Linkaza marketing website. `app.linkaza.com` is a separate application and is outside this codebase.

The current site uses Next.js 16 App Router, React 19 and TypeScript. Arabic lives at `linkaza.com`; the English production site lives at `en.linkaza.com`. Local English routes use `/en`. The same deployment must serve both domains and enable the production variables described in `.env.example` and `README.md`.

Key files:

- `src/app/[[...segments]]/`: statically generated bilingual pages and locale-specific document layout.
- `src/lib/content.ts` and `src/lib/articles.ts`: substantive localized copy.
- `src/components/`: design, marketplace demonstration and interactions.
- `src/proxy.ts`: production subdomain routing and old `/ar` redirects.
- `src/app/robots.txt/route.ts` and `src/app/sitemap.xml/route.ts`: host-aware search files.
- `public/og-ar.png`, `public/og-en.png`: generated by `npm run generate:og`.
- `tests/` and `scripts/audit-routes.mjs`: browser and SEO checks.

The marketplace preview contains illustrative data only, clearly marked as such. Real inventory, prices and order details belong to the application. Do not invent them in marketing copy. Do not claim guaranteed rankings, traffic, site counts, reviews or global placement guarantees. Keep paid link disclosure and Google link attributes accurate.

Run `npm install`, `npm run dev`, `npm run build`, `npm test`. Run the browser suite against a started site with `npm run test:e2e`. See `README.md` for launch requirements. Historic plans in `docs/linkaza-master-plan.md` describe the former template and are not implementation instructions.
